# Trainings-Tracker online stellen (GitHub Pages)

1. Kostenloses Konto auf github.com anlegen und einloggen.
2. Oben rechts auf „+“ → „New repository“. Name z. B. `training`, auf „Public“ lassen, „Create repository“.
3. Auf „uploading an existing file“ klicken und alle Dateien aus diesem Ordner hineinziehen
   (index.html, manifest.json, service-worker.js, icon-180.png, icon-192.png, icon-512.png). „Commit changes“.
4. Im Repository: „Settings“ → „Pages“ → bei „Branch“ `main` und `/ (root)` wählen → „Save“.
5. Nach 1 bis 2 Minuten ist die App erreichbar unter:
   https://DEIN-GITHUB-NAME.github.io/training/

## Auf dem iPhone installieren
Link in Safari öffnen → Teilen-Symbol → „Zum Home-Bildschirm“ → „Hinzufügen“.
Das Hantel-Icon wird automatisch übernommen, die App startet ohne Browserleiste.

## Auf Android installieren
Link in Chrome öffnen → Menü (drei Punkte) → „App installieren“ bzw. „Zum Startbildschirm hinzufügen“.

## Wichtig zu den Daten
Alle Trainings werden nur auf dem jeweiligen Handy gespeichert. Jede Person hat also automatisch ihre eigenen Daten.
Über „Exportieren“ in der App regelmäßig eine Sicherung machen (z. B. in iCloud Drive oder per Mail an sich selbst),
mit „Importieren“ lässt sie sich auf einem neuen Gerät wiederherstellen.
